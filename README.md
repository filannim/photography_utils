Photo Utils is a small collection of free tools for inspecting used photography equipment before buying. Everything runs in the browser: no account, no external service, and no tracking.

## Tools

- [Body Inspector](body_inspector.html): a checklist for camera bodies, with technical and financial evaluation.
- [Lens Inspector](lens_inspector.html): a checklist for lenses, covering optical, mechanical, electronic, and image-performance checks.

The [home page](index.html) brings both tools together and provides quick navigation between them. The interface supports Italian, English, Spanish, German, and Simplified Chinese.

## Run locally

Open `index.html` directly in a browser or serve this folder with any static web server. Inspections are stored in the browser's local storage and can be exported as JSON or printed as PDF.

## Publish on GitHub Pages

1. Create a public repository and push the contents of this folder to the published branch.
2. In **Settings > Pages**, choose GitHub Actions or a branch and the `/root` folder.
3. Open the URL generated by GitHub Pages. Relative links also work when the repository is published under a project subpath.

No build step is required: GitHub Pages can publish the HTML, CSS, JavaScript, and local SVG files directly.

## Install as an iOS app icon

On an iPhone or iPad, open the page in **Safari**, tap **Share**, choose **Add to Home Screen**, and confirm. The page can then be saved as an app icon and reopened quickly as a utility, especially after publishing it on GitHub Pages.

## Structure

- `index.html`: public home page.
- `body_inspector.html` and `lens_inspector.html`: offline utilities.
- `shared.css` and `shared.js`: branding, navigation, languages, and local illustrations.
- `assets/logo.svg` and `site.webmanifest`: installable identity and metadata.
